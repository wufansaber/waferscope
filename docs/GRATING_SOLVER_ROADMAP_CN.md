# 光栅仿真求解器主线与验收规则

更新日期：2026-10-27。此文更新后续开发优先级，不改变历史结果的真实后端。S4 已完成零级、裸背景及颗粒联合局部加密检查，并与 grcwa 做了匹配几何的实现核对；第五轮增加连续角度诊断，第六轮补齐三个 X 超胞，第七轮完成固定胞长的单独 X 截断检查。该截断局部步通过，但超胞序列的复场门槛仍未通过；孤立缺陷和独立物理方法验证尚未完成。

**本次新增源码 UI 的完整周期光栅工作流**：S4 原生 XY/XZ/YZ 近场、离散远场、独立三路收光、理想相干中继，以及像元面积积分后的模拟面阵相机/原始 DN 时间统计 SNR。采用接触球 `gap=0` 的新系列，不覆盖旧 `gap=10 nm` 对照记录。功能链路完成不代表数值/孤立极限认证完成，详见 [本轮开发与实算验收](GRATING_SCENE_DEVELOPMENT_CN.md) 和 [操作说明](GRATING_SCENE_GUIDE_CN.md)。

## 1. 决定

**主线采用 S4：先建立周期光栅及颗粒三维超胞 RCWA，再接入收光、成像与相机。**

- grcwa：保留为辅助对照和算法诊断，不再作为替代 S4 的主线。
- 现有 FEM：保留为独立离散方法对照，尤其用于有限边界、局部颗粒耦合、近场和远场提取验证；不删除、不强制匹配其他求解器。
- cRCWA/三维 AFMM：候选评估项；第六轮已隔离构建原生命令行工具并通过平面界面/官方小波导检查，但尚无通过验收的 AFMM/PML 孤立缺陷结果，不替换 S4。
- SCATMECH RCW：用于同几何无限周期直线光栅的逐衍射级基准。
- Bobbert-Vlieger：仅在适用的平整晶圆颗粒条件下作基准，不能直接认证颗粒加光栅。

S4 和 grcwa 都是分层周期 Fourier modal/RCWA 求解器，都可以表示横向双周期、垂直分层的三维结构；不是只有 S4 能做三维。

## 2. 选择依据

目标是高折射率晶圆、尖锐介电边界、光栅和球形颗粒，以及相位敏感的 sample/reference 成像。S4 提供圆、矩形、多边形等图形与多种偏振/Fourier 因子化设置，可减少在本项目中继续自行扩展材料矩阵的范围。它因此被选为更值得优先验证的主线，而不是被预先认定为准确答案。

grcwa 的 Python、自动微分和优化接口很有价值，但自动微分并非当前需求。其官方基本路径支持逐层二维介电网格。本轮新增的解析直线光栅矩阵属于本项目适配，不代表整个三维颗粒结构都已获得解析材料表示或完成收敛。

S4 并不自动保证精度、运行速度或较小内存；具体版本、编译选项、基底和误差需要实测。S4 与 grcwa 同属 RCWA，二者一致属于独立实现交叉检查，不等同于不同物理方法的完全独立认证，因此保留 FEM。

官方依据：

- [S4 Fourier modal formulations](https://web.stanford.edu/group/fan/S4/tutorial.html)
- [S4 Python API：几何、复振幅和功率接口](https://web.stanford.edu/group/fan/S4/python_api.html)
- [S4 源码](https://github.com/victorliu/S4)
- [grcwa 官方源码与说明](https://github.com/weiliangjinca/grcwa)
- [Li 1996 Fourier factorization](https://doi.org/10.1364/JOSAA.13.001870)

## 3. 当前真实状态

1. 当前已实算 grcwa 和真正的 S4；cRCWA 已执行小型界面/波导检查，AFMM 孤立光栅加颗粒尚未实算验收。S4 的输入 Lua、原始复振幅、逐级功率、构建信息均保留在 `output/s4_validation_20261022/`。
2. grcwa 已有平整晶圆 Fresnel 幅相检查、超胞颗粒试算和 NIST 裸光栅对照；未完成孤立缺陷与定量成像认证。
3. 2026-10-22 增加解析矩形光栅卷积、Li 一维材料规则、精确不变子块求解和各向异性阶数设置；相应新增/原有 RCWA 回归共 28 项通过。
4. 裸直线光栅的精确子块减少只适用于其对称性，不能用于有颗粒的整体结构。本项目代码对颗粒算例禁用该整体缩减。
5. 结果位于 `output/rcwa_grating_20261022/`；保留 `modes.npz`、参数、资源记录与 NIST 复振幅。高阶背景总反射率接近并不自动认证所有弱衍射级、三维近场或颗粒。
6. S4 使用项目私有便携工具链、Lua 命令行和官方 RNP 特征值求解器；未更改 NIST2、FEM 或系统环境。真空、Fresnel s/p 幅相、近场相位、零对比度与弱对比度检查通过。本轮 S4 与既有 grcwa 相关测试共 69 项通过。
7. S4 一维 731 模式（±365）裸光栅与同截断 NIST RCW 总反射率相对差约 `9.35e-11`，功率加权复场相对差约 `5.29e-11`，没有幅相拟合。这是同几何、同截断的实现一致性，不代表三维模型或真实材料达到此精度。
8. S4 三维超胞默认展开从 121 加到 319 模式时，颗粒差分复场变化仍为 17.37%；背景增至 641 模式后仍未收敛。内置 normal/vector/Jones 选项也未使本轮三维背景达到验收线，不推荐将它们直接用于定量成像。
9. 详细构建、复现及边界见 [S4 验证记录](S4_VALIDATION_CN.md)。原有 GUI/FEM 没有被这些试验替换。
10. 第二轮加入独立、显式启用的条纹层 Li 数值适配与矩形基组，不是未修改官方功能。二维背景相对 NIST 总功率差 0.04703%、复场差 0.05444%；颗粒单独增加 X/Y 截断仍变化 2.6574%/3.9592%，未达 2% 目标。相关测试 78 项通过，见 [第二轮记录](S4_ROUND2_CN.md)。GUI 尚未切换到该试验后端。
11. 第三轮从 `Mx=3,My=40,8 层` 分别增加 Mx、My 和切片数，复差场变化为 0.43183%、0.27596%、0.99487%，每路差场功率变化均小于 1.39%，通过局部加密门槛。88 项测试通过；最高峰值统计约 1.81 GiB。尚无联合最高截断解或超胞扫描，不宣称整体收敛。层复制提速因近场回归未通过已撤回。原始数据、明确的比较计划与边界见 [第三轮记录](S4_ROUND3_CN.md)。

## 4. 固定的模型约定

第一至第七轮数值对照起点采用 266 nm、75 度、p 偏振，光源来自 -KY，光栅周期 500 nm、线宽 250 nm、深度 100 nm；颗粒直径 100 nm、间隙 10 nm。新 UI 的接触系列使用间隙 **0 nm**，其收敛记录单独列出，不把旧间隙的验收结论移植过去。所有参数必须写入每次报告，不能仅用本文件作为计算输入。

沿用的 Si `n=5.57, k=0.387`、颗粒 `n=1.59, k=0` 只为可控数值对比，不宣称为经 266 nm 标定的真实材料输入。高斯照明建模修改仍按原决定暂缓。

S4、grcwa 和 FEM 比较时必须匹配材料、几何、坐标、入射偏振、参考面、功率归一化及边界。周期超胞与有限两沟槽不能直接当作同一个问题。周期球的间距和球体垂直分层也必须明确。

## 5. 按顺序验收

1. **环境与零级问题**：隔离构建 S4，记录源码提交、前端及数值依赖；以无结构介质、平面界面 Fresnel s/p 复反射系数检查符号和归一化。
2. **裸周期光栅**：匹配 NIST RCW，比较各传播级的方向、复幅相和功率；同时记录总反射率与弱级绝对误差，不能只比较总量。
3. **平面上的周期颗粒**：无颗粒参考与有颗粒样品成对计算，独立扫描模式截断、球体分层和超胞尺度；接近孤立极限后才与 Bobbert-Vlieger 的对应量比较。
4. **同一光栅加同一颗粒**：S4 为主，grcwa 为辅；比较原始复反射级次、三路独立收集功率、差分复场功率和真实功率差。禁止幅相拟合、强制左右对称或按结果调归一化。
5. **再接成像**：基于已核对的相位参考和功率，传播 sample/reference 场；真实强度差保留相干交叉项，不能以差分场强度替代。
6. **有限边界候选**：FEM 与经小基准验证的 AFMM 等再评估。周期超胞收敛不等于有限光栅端点问题已解决。

建议初始检查目标：总反射率相对差小于 1%，显著传播级功率相对差小于 5%，功率加权复场差小于 2%；弱级另列绝对误差。上述是项目验收门槛，不是理论误差保证，必须连同截断、分层、超胞和独立基准敏感性一起报告。

任何安装或计算失败都如实记录，不将 grcwa 输出改名为 S4。没有通过上述检查的模型不进入定量相机 SNR 结论，也不以继续增加内存替代算法与物理校验。

## 6. 当前未完成的物理验收

1. 接触球新系列继续检查联合 Fourier 截断、球切片和特征求解稳定性。部分 Mx=4 算例出现约 3.6%~4.0% 的全传播差场 X 镜像误差，尽管两侧功率差只有 0.20%/0.051%；不能只看总功率。Mx=5、My=32、16 切片联合解的对应镜像误差约 5e-8。未定位为真实物理效应，也未通过事后对称化掩盖。
2. 继续原有连续电流/超胞孤立极限序列。新 GUI 离散级图与旧连续 DSC 诊断严格区分，有限光栅端点和孤立缺陷仍需要 FEM 或已验收的有限边界求解器。
3. 使用经波长标定的 PSL/晶圆 n、k。以本轮继承常数得到的相机 SNR 仅用于代码链路测试。
4. 实际镜组、斜视几何、有限照明、haze/膜层和真实相机测量对照。相机噪声模块的正确性不等于输入光学场正确。
