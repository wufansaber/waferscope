# DFI Simulation 2026-10-19

Windows x64 分文件实验版，完整解压后运行 `DFI_Simulation.exe`。
必须保留 `_internal` 与 `fem` 文件夹，无需另装 Python、Anaconda 或 NGSolve。

## 更新内容

- 软件名称、窗口标题、主程序与求解器文件名、手册封面统一为 DFI Simulation。
  为兼容旧结果，用户数据目录仍保留原来的 FarField_Simulation 名称。
- FEM 增加横线、竖线、十字有限缺陷及尺寸、厚度与旋转设置。
- 根据缺陷大小自动扩大计算域，近场和像面视图适配图案范围。
- 附带 21 页中文操作手册与 10 页功能案例手册，以及可查看的案例数据。
- 案例混合远场按 401×401 方向网格重算，共 125609 个有效半球方向，替换旧 5° 采样图。
  使用同一保存散射源，并非平滑旧强度图；保留真实相干散斑。
- 加密图仅更新文档案例，未改变所有 UI 远场计算的默认角度采样。

## 校验与限制

发布前主环境回归测试 367 项通过、20 项跳过；另在 NGSolve 环境完成 4 项原生几何检查。
两份 PDF 已完成内容核对，操作手册 21 页、功能手册 10 页均已逐页检查。
本次发布包的独立运行检查结果另随包提供于 `verification`。

FEM 和混合算法仍属实验模型。尤其大尺寸十字缺陷尚未达到网格/尖角收敛，
不得把预览形貌、两侧亮度差或 SNR 当作硬件标定结果。
相机采用面阵近似，不累计 TDI 级数；转换增益等暂估量仍需实测标定。
单张粗糙面的散斑和统计 PSD 平均分布不应混同。
