# 周期光栅全链路开发与实算验收

日期：2026-10-27。对应源码页面：`S4 Grating (periodic)`。

## 本轮完成的功能

同一套输入贯通了：三维光栅/球形缺陷几何、原生 Maxwell 近场 XY/XZ/YZ、周期离散远场、三路独立 NA/倾角收光、复场相干中继、sample/reference 真实强度差、像元面积积分、面阵相机噪声/ADC，以及原始灰度时间统计 SNR。

界面支持异步求解、取消、自定义工作环境、独立光学重算、结果加载、原始数据 ZIP 导出、逐项截断/切片对照及物理一致性诊断。原有 SCATMECH 和 FEM 页面保留；没有将它们的结果改名为 S4。

**功能链路已实现，整体物理精度尚未全部验收。** 当前是平面波照明的无限周期超胞，不是孤立颗粒、有限光栅、有限照明、真实斜物镜或 haze 的完整实机模型。本次没有打包或修改 GitHub，已有 EXE 不会自动更新。

## 固定输入

本轮新系列均采用球底接触脊顶的 **gap=0 nm**，不沿用旧轮次 gap=10 nm 的收敛结论。

| 参数 | 本轮值 |
|---|---|
| 波长 / 入射角 / 偏振 | 266 nm / 法线起 75 度 / p |
| 入射方向 | 光源位于 -KY，传播投影 +KY |
| 光栅 | 沿 X 不变，Y 周期 500 nm，脊宽 250 nm，刻蚀深 100 nm |
| 超胞 | X=0.5 um，Y=1 um，两条周期 |
| 球 | 100 nm，底部间隙 0 |
| 晶圆 n+ik | 5.57+0.387i |
| 球 n+ik | 1.59+0i |
| 三路 | NA 都为 0.6，绕 Y 倾角 +45/-45/0 度 |
| 照明幅度 | 参考晶圆面 2x2 um 上 1 W；不是有限 2x2 um 光束 |

这些 n、k 是继承的受控对照输入，**不是经 266 nm 标定的真实 PSL/晶圆材料常数**。每个输出仍保留自己的完整输入快照。

使用私有 S4 stripes 二进制，SHA256：

```text
1da0f38040f8f8b168269280fd7c013c536a84a252bcb7f2fb08b898f2271741
```

该后端包括已留档的条纹 Li 规则与矩形基组数值适配，不是完全未修改的官方构建。RNP 特征求解路径未切换；旧外置 LAPACK 路径的失败记录仍保留。

### 镜像和能量诊断

- 裸光栅反射场的 X 镜像复误差约 1e-14。
- 4/32/8 和 4/40/8 算例的全传播差场镜像误差约 3.62%、3.99%；两侧功率不对称度分别只有 0.197%、0.0513%。这是待定位的数值一致性问题，不解释为真实左右物理不对称，也没有事后平均或强行对称化。
- 5/32/16 联合解的差场镜像误差约 5.01e-8，两侧功率不对称度约 2.19e-8。该算例自身对称性较好，但相对较低截断解仍未通过联合收敛。
- 原生 E/功率核对约 1e-16，传播级横向性约 1e-16；R、进入衬底的 T 及 1-R-T 均满足被动性检查。**1-R-T 是通量差额，尚不是独立吸收体积分。**

因此，后续优先级是接触球条件下的联合截断/切片和特征求解稳定性，而不是继续将显示图平滑或调整通道亮度。

## 近场、像面和相机验证

1. 将所有反射模态（含倏逝级）与入射波叠加，在空气中重建 E/H，与原生 GetFields 在 550 个点逐点核对；预览和 4/24/8 联合近场的相对误差约 1e-15。证明导出接口的相位与坐标一致，不证明截断精度。
2. Jones 中继用独立的直接 Fourier 求和核对 FFT，按绝对单位检查 Parseval；覆盖倍率缩放、NA=0、分析器分解、透过率、偏振输运和相干交叉项。没有以差场强度替代真实强度差。
3. 相机对强度 Fourier 自相关做解析方形像元积分，独立 Gauss 积分核对至浮点精度，并检查一个放大超胞的绝对功率。未以截图插值计算像元信号。
4. 复用既有面阵相机读出核心：光子/暗电流 Poisson、读出噪声、PRNU/DSNU/DCNU、满阱、增益、ADC 和固定种子。原 FEM/SCATMECH 的采样入口保留；抽出像元功率读出函数避免重复噪声实现。
5. 从保存的 uint16 原始帧重新计算 sample/reference ROI 和的时间 SNR。所有无效、饱和和未知值保持无效，不以光子预算 SNR 冒充灰度实算。
6. 实际 Qt QProcess 流程覆盖 Calculate、Update optics、相机计算、两个完整 ZIP、取消原生子进程；原始模态 SHA256 不变，取消后没有遗留所拥有的子进程。

原生源数据、对照与哈希均在 `output/grating_scene_20261027/`；聚合报告由 `tools.grating_scene_report` 从这些记录重算，不靠手填结果数组。

## 相机测试例

明确测试条件：5/32/16 联合原生场，理想中继 **40 倍、功率透过率 1e-6**。使用 Gemi 面阵近似，5 um 像元，4 列 x 8 行，曝光 0.01 ms；ROI 恰好覆盖一个 20x40 um 放大超胞。每组 1 张 sample 和 1 张 reference，共 **5000 组**。

QE=0.639、读出噪声=12.1 e-、满阱=16000 e-；ADC=10 bit，增益=16 e-/DN、黑电平=64 DN。增益、黑电平和暗电流是假设，非实机标定；详细限定见操作说明和既有 Gemi 预设注释。

| 通道 | 原始 DN 时间 ROI SNR | 状态 |
|---|---|---|
| CH1 | 28.6695 | 未发生满阱或 ADC 触轨 |
| CH2 | 29.0734 | 未发生满阱或 ADC 触轨 |
| CH3 | 7.5118 | 未发生满阱或 ADC 触轨 |

这里的两侧差异包含独立传感器固定图案和有限次随机噪声采样；没有强迫相同随机序列。中路的参考光栅背景较亮，sample 和 reference 都有散粒噪声，因此更亮不保证缺陷差值 SNR 更高。

这些数值仅证明代码流程可以闭合。输入光学场未完成收敛、材料未标定、镜组理想化且没有 haze，因此**不应作为实际 100 nm PSL 探测性能**。
