# FarField Simulation 2026.10.16

## 界面与相机

- 新增 `266 nm low-haze camera` 预设，包含 100 nm 颗粒、0.2 nm RMS 粗糙面及三路收光配置。
- 支持 Gemi 相机面阵模式参数，不采用 TDI 级数累加。
- 新增灰度帧采集、SNR 结果表及“仅重算相机”操作；可复用保存的光学结果，无需重新求解 FEM。
- SNR 使用独立样品帧和参考帧的 ROI 灰度差计算，单独显示预测值与灰度统计值。支持导出原始整数灰度帧、TIFF 和统计 CSV。
- 修复小透过率和 PRNU 输入精度不足的问题。
- 新增已保存的 NIST haze 与通道对称性校验结果查看入口；该入口不代表按当前 UI 参数重新计算。

## 校验与限制

- 源码回归测试：334 项通过，16 项因环境或可选条件跳过。
- 低粗糙度案例已通过源码 UI、计算进程及 5000 对原始灰度帧的独立 SNR 复算。
- 发布包的 `verification` 目录包含验证报告；打包程序的实际运行结果以该目录内的报告为准。
- Gemi 的 16 e/DN 增益及部分噪声参数仍有假设，需用实测标定值替换；266 nm QE 不应直接用于其他波长。
- 灰度帧 SNR 是给定模型参数下的模拟统计结果，不等同于实测相机 SNR；饱和或灰度截断时会标记无效。
- 整光斑粗糙面采用一阶 SPM，与局部 FEM 配对组合，尚不是整片粗糙晶圆的全波求解。高阶耦合、网格收敛及统计不确定度仍有边界。
- 本版未修改此前暂缓的高斯照明建模方案。

## 安装与运行

下载 ZIP 并完整解压，运行 `FarField_Simulation/FarField_Simulation.exe`。必须保留同目录的 `_internal` 和 `fem` 文件夹，不要仅复制 EXE。无需安装本项目的 Python 环境。

操作说明见 `docs/far_field_standalone/OPERATION_MANUAL_CN.md`。SHA256 文件可用于校验 ZIP 完整性。
