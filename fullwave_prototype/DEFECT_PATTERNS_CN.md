# 有限尺寸图案缺陷

2026-10-17：FEM/混合模型页增加球体、横线、竖线和十字三维几何。SCATMECH 的球体模型没有被改成图案模型。

## 几何定义

| 选项 | 实体形状 | 尺寸定义 |
| --- | --- | --- |
| `sphere` | 球体 | 原有直径参数 |
| `line_x` | 沿晶圆 X 方向的有限长方体 | 长度 L、线宽 W、高度 H |
| `line_y` | 沿晶圆 Y 方向的有限长方体 | 长度 L、线宽 W、高度 H |
| `cross` | 两个等长等宽正交臂的并集 | 每臂端到端长度 L、线宽 W、高度 H |

L、W、H 单位均为 nm，要求 L >= W > 0、H > 0。绕 +Z 轴的旋转角遵循从 +X 朝 +Y 的正角定义。十字使用一个凹多边形挤出，不是把重叠处当两份介质，其体积为 `(2 L W - W^2) H`。横竖线体积为 `L W H`。

缺陷中心位于 X=Y=0；底面 z=`gap_nm`，顶面 z=`gap_nm+H`。材料仍由 Defect n、k 设置，不因选择图案而自动改变材料。

这是晶圆上方的**凸起实体**，不是凹槽、无限长划痕、周期光栅或二维掩模透过率。粗糙面启用时，底面须高于实际最高表面；目前没有实现实体与随机粗糙面贴合或嵌入，程序会拒绝交叠。

## 使用

在 `Full-wave FEM (experimental)` 页选择 `Defect shape`，调整长度、线宽、高度和旋转角。球体直径在非球形模式禁用。XY 预览使用全局晶圆坐标，照明传播投影仍为 -Y 向 +Y，不随图案旋转。

可直接选择 `266 nm line X preview`、`266 nm line Y preview` 或 `266 nm cross preview`。这些预设采用 L=200、W=50、H=50、gap=10 nm，平整晶圆、一阶预览网格、手动平面波照明和三路 NA=0.5。相机沿用 Gemi 面阵近似，100 对灰度帧，透过率 1e-6 以避免示例饱和。不是网格收敛后的最终精度配置。

几何栏显示体积和所需物理域最小半径；缺陷超出当前求解区域时，UI 自动将 Domain radius 扩大到最小半径的约 1.2 倍，并按输入框精度向上取整，不再因此弹出“缺陷超出物理域”警告。当前半径已足够时不变，缩小缺陷也不自动缩小计算域；该修正不改变缺陷、网格步长、FEM 阶数或线程数。命令行和模型底层仍保留严格几何校验。扩大区域本身仍会增加网格总量和内存/时间，不等于已经获得物理收敛保证。

点击 Calculate 重新求解。近场 XY 切片位于真实实体中高处；XZ/YZ 轮廓也使用实际形状。后续远场、三路独立收光、像面和相机沿用矢量复场流程。

近场矩形采样窗口的四角必须位于物理域内，靠近球形域边缘的长十字可能显示不全；应在仅满足实体容纳条件之外留足背景区域，而不是把 PML 内的场当作物理近场。

修改形状或几何尺寸不能通过 Re-image 或仅重算相机生效：它们复用保存的散射场。新计算与报告保存完整形状参数；旧报告缺少形状时按球体加载，不继承当前控件中另一种形状。

## 物理边界

- Bobbert-Vlieger/Mie 是球体参考，不能作为十字、横线或竖线的解析解；相关入口会拒绝这些形状。
- 锐边、尖角处的局部场对网格非常敏感。此版没有圆角，不能将角点峰值解释为已经收敛的物理热点。
- 必须根据最小线宽/厚度做网格、PML 和远场积分收敛；求解残差通过不等于物理误差收敛。
- 亚波长图案经过有限 NA 和相机像素积分后可能只是模糊光斑，不保证像面呈现清晰十字。
- 整光斑粗糙度仍为一阶 SPM 加局部 FEM 修正，不是全晶圆全波解析解。高斯照明的暂缓改进不在本次修改范围内。

源码入口保持 `far_field_standalone/main.py`；2026.10.16 的已发布 EXE 不包含本次新增图案，需要更新源码运行或重新打包。

## 本机功能验证

三种平整面图案，以及 0.2 nm RMS、L=0.1 um、5x5 高度节点的十字粗糙面案例均实际运行了配对 FEM、XZ/XY/YZ 近场、远场、三路像面和模拟灰度采集。长度 200 nm、宽 50 nm、高 50 nm；入射 266 nm、75 度、p 偏振。网格材料体积与解析几何体积相对差小于 3e-14，线体积 0.0005 um^3，十字体积 0.000875 um^3。

该功能验证使用手动平面波归一化，并没有验证整光斑有限高斯图案耦合的收敛。100 帧模拟 SNR 只是管线验收，不是高精度检出率结论。较密 9x9 粗糙面第一次试算触发 8 GiB 保护，保留其失败记录，不能视为通过。最终成功案例和资源记录在 `build/defect_patterns_20261017/validated`。

复算几何与数值功能检查：原生 FEM 环境运行 `python -m tools.validate_defect_patterns --include-rough`。绘制同绝对标尺对照及检查 UI 重载：NIST2 环境运行 `python -m tools.defect_patterns_preview`。

本次 NIST2 回归为 350 项通过、20 项跳过；其中原生 CAD 测试因该环境无 NGSolve 被跳过，另在原生环境实际完成 CAD/材料体积检查和上述四个场计算。UI 在 1680x980 和 1200x800 下完成截图检查，并通过 `--solve-ui` 实际点击十字预设的 Calculate 流程。图像、灰度帧与验证记录均保存在上述 `validated` 目录，`pattern_comparison.png` 对比图的每一行共用绝对色标，没有逐图归一化。
