# 整光斑 SPM 与局部颗粒 FEM 的相干混合模型

最新的范围/网格/能量闭合、128 张统计及真实照明定义见 [本轮实现与校验记录](ROUGHNESS_CAMPAIGN_CN.md)。以下保留原模型说明与历史结果，不将范围审计误称为生产窗口自动更新。

## 当前完成的工作

本轮实现了优先级第 1 项的计算入口，并加入第 2 项的同表面数值诊断。
这不是整片晶圆的严格全波 FEM，也不是已经完成物理收敛的生产模型。

FEM 页新增 `Particle + whole haze (hybrid)` 和 `Re-image hybrid`。
原局部 `Calculate`、局部 haze 平均、整光斑 `Whole-beam haze (SPM)` 均保留。
新入口输出局部 XZ / XY / YZ 近场、混合远场、三路独立像面、
相干分解以及同表面范围/积分检查。照明页显示整面高度、真实入射光斑和局部 FEM 框。

## 复场连接方法

全部振幅使用同一界面原点、出射 s/p 基、时间约定 exp(-i omega t)
和中心入射通量基准。首先生成并保存一张较大的平稳随机母表面：

1. 整光斑粗糙面从母表面中央裁剪，不强制逐张 RMS 和均值。
2. 局部 FEM 节点由同一母表面插值得到，保存绝对高度并保留 DC。
3. FEM 内使用实际的渐隐三角面；局部一阶项也积分这张实际三角面。
4. 扣除局部一阶复振幅，再加入配对 FEM 的局部全波复振幅。

```text
A_hybrid,with    = A_whole,SPM + A_local,FEM,with    - A_local,SPM
A_hybrid,without = A_whole,SPM + A_local,FEM,without - A_local,SPM

Delta A_hybrid = A_local,FEM,with - A_local,FEM,without
DSC = |A_s|^2 + |A_p|^2                  [um^2 / sr]
```

这是一种局部响应修正的工程近似，并非引用某篇论文中的严格整面解。
减法在复振幅上进行，不能改成强度相减或者将两幅强度直接相加。
局部 FEM 高度存在三角插值与边缘渐隐，整面 SPM 使用较细的高度网格；
因此它也不等同于对一张完全一致的离散几何直接求解整个 Maxwell 系统。

一阶表面项的公式和单位见 [整光斑 haze 文档](WHOLE_BEAM_HAZE_CN.md)。
基础理论参照 NIST
[Microroughness_BRDF_Model](https://pages.nist.gov/SCATMECH/docs/microroughbrdf.htm)：
它属于光滑表面极限、单界面、无膜的一阶矢量 Rayleigh-Rice 理论。
本项目的一阶核已经通过同参数 NIST s/p 绝对 DSC 对照，但这只验证核和单位，
不为上面的混合算法、强粗糙度、高阶耦合或有限域 FEM 提供准确性保证。

## 照明和成像

当前新入口支持 Gaussian/ABC PSD 与有限、完全相干的 Gaussian 照明。
长 L 沿晶圆 Y，宽 W 沿 X，均为目标强度 1/e^2 直径，不是矩形硬边。
总功率按整束入射 Poynting 通量归一；扩大粗糙区域不会重新定义光斑或总功率。
入射光从 -KY 一侧传播，中心方向为 (0, sin(theta_i), -cos(theta_i))。

三路是独立的理想空气物镜，可以分别设置 NA 和倾角。NA=0 关闭该路。
默认物镜焦距 20 mm、倍率 20，因此等效 tube 焦距 400 mm。
混合复场直接进入矢量出瞳传播，保留偏振、可选检偏器、像差和相机设置。
背景与粒子变化场会在像面相干干涉：

```text
I_total = I_background + I_changed_field + I_signed_interference
```

`Changed-field` 包含颗粒引起的局部粗糙面响应变化，不是脱离晶圆的孤立颗粒。
像面功率为绝对 W、强度为 W/um^2；三路共用标注的绝对色标。
功率守恒与相干分解通过检查，不表示材料、FEM 网格或光学模型已经实验校准。

近场图始终标注 `LOCAL FEM`。目前没有重构外部整光斑粗糙面产生的近场，
不能把这三张局部平面图理解为整个粗糙晶圆的混合近场。

## 同表面收敛检查

`hybrid_surface_audit.json` 自动保存以下诊断：

- 固定母表面、固定渐隐的物理宽度，比较约 0.8 / 1 / 1.25 / 1.5625 / 1.875 倍窗口。
- 网格点数翻倍，采用母表面的 Fourier 插值，保持同一带限实现，不生成新随机模式。
- FFT 补零 2 与 4 的比较，以及选定方向的独立空间 Fourier 求和。
- 三路圆锥 Gauss 立体角积分的 64 / 96 阶比较。
- 在最大检查窗口独立提高照明角谱阶次，避免把照明积分误差误认为范围误差。
- 比较提高角谱阶次后原始窗口上的加权背景复场；生产 FEM 来源不被偷偷替换。

检查报告明确区分总功率和选定方向复振幅。全部检查只作用于整面一阶项，
局部 FEM 修正保持不变；它不是 FEM 网格/PML、PSD 高频尾、样本统计或出瞳收敛证明。
Fourier 加密也不能补回原母表面没有生成的 PSD 高频分量。
检查未通过时保留 `outer_spm_numerical_target_met=false`，不会将 99% 入射覆盖标成 1% 散射误差。

## 2026-10-09 实际验证

输入：266 nm、100 nm 球、粒子 n=1.59/k=0、基底 n=5.57/k=0.387，
75 度 p 偏振、间隙 10 nm、1 W、2x2 um Gaussian，
Gaussian 粗糙度 RMS 2 nm / L=0.05 um、seed=7，三路 NA=0.5、倾角 +45/-45/0 度。
材料 n/k 是固定测试输入，不代表已经验证了 266 nm 下真实 PSL/晶圆的色散与吸收。

本地输出位于 `build/hybrid_20261009/`：`result` 保存复源，`verified` 保存最终检查与图像。

| 项目 | 结果 |
| --- | --- |
| 整面粗糙区域 | 7.5x7.5 um、256x256 网格 |
| 母表面 | 15x15 um、512x512，保存全局坐标与 SHA256 |
| 局部 FEM | 0.2x0.2 um、9x9 高度节点、54440 自由度、一阶预览 |
| 渐隐平方加权入射覆盖 | 99.2938% |
| 三路总散射像面功率 | 0.721049 / 0.825125 / 0.743022 mW |
| 混合粒子变化场代数一致性 | 相对 L2 误差 1.04e-16 |
| 局部 FEM 背景与同三角面 SPM 复振幅差异 | 10.36%，尚未物理收敛 |
| 原窗口加权背景场：41 阶与审计 81 阶 | 相对 L2 变化 2.65e-8 |
| 独立空间 Fourier 与 FFT 插值，选定方向 | 相对 L2 差异约 1.36e-5 |
| 256 到 512 积分网格 | 三路收集功率相对变化均小于 1e-6 |
| 7.5 到 9.375 um | 三路一阶收集功率变化约 0.154% / 0.473% / 0.348% |
| 11.71875 到 14.0625 um | 选定方向复振幅相对 L2 仍变化约 2.57% |
| 完整初次流程资源 | 543.55 s，采样计账峰值约 4.84 GiB |

因此，当前粗糙范围对集成功率较稳定，但对相干复场的 1% 目标仍不够。
窗口外光束尾部对弱方向的相干叠加不能只凭能量覆盖率忽略。
审计在最大窗口使用 81 阶；41 到 61 阶变化约 0.609%，61 到 81 阶约 7.22e-8。
生产 7.5 um 窗口的 41 阶与更高阶场差异很小，不需要用高阶审计重做这次局部 FEM。

另一次重成像将功率改为 2 W，并将第 1 路 NA 改为 0：第 1 路全部为零，
第 2/3 路每像素的总场、背景、变化场及干涉强度均按两倍缩放。
该过程不重新求解 FEM，母表面和局部复源保持不变。

## 重成像与追溯

完整来源包括 `hybrid_fields.npz`、`hybrid_source_report.json`、
`shared_surface.npz/json`、`local_shared_height.npz/json` 和原始输入。
程序验证母表面与复源指纹，拒绝在物理输入或来源变化后继续复用旧场。
加载新混合结果后只能通过 `Re-image hybrid` 自动复用它，不会误用局部 FEM 出瞳缓存。
改变光斑尺寸、入射角、材料、颗粒或 PSD 需要新的散射计算。
仅改变总功率、三路 NA/倾角、光学传播与相机参数可重成像。
