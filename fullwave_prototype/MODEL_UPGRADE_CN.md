## 1. 有限照明模型

`Beam waist` 为 0 时，完全沿用原平面波。大于 0 时，它是垂直中央入射方向的
近轴光束 1/e 电场半径（1/e² 强度半径），单位 um。束腰参考中心为晶圆原点。
中央方向仍从负 KY 一侧入射。波束不是把求解后的场乘一个高斯包络。

设中央单位方向为 d，横向正交基为 s、p。使用二维 Gauss-Hermite 求积：

```text
u_i = 2*x_i/(k0*w0), v_j = 2*x_j/(k0*w0)
k_ij = u_i*s + v_j*p + sqrt(1-u_i^2-v_j^2)*d
E_inc(r) = C * sum_ij [w_i*w_j/pi * e_ij * exp(i*k0*k_ij dot r)]
H_inc*Z0 = C * sum_ij [w_i*w_j/pi * (k_ij cross e_ij) * exp(i*k0*k_ij dot r)]
```

`e_ij` 由中央偏振最小旋转到各射线，满足 k·E=0。各射线分别计算 Fresnel 反射、透射，
因此均匀介质内满足 Maxwell 方程，界面切向 E/H 连续。C 使参考原点的
入射轴向通量 `Re(E cross H*) dot d = 1`；UI Irradiance 是这里的物理辐照度，
不是束总功率，也不是晶圆法向投影通量。沿用的 DSC 单位 um²/sr 此时是相对该参考
辐照度的归一化辐射量，不应直接套用平面波总散射截面公式。

阶数可选 3/5/7/9，必须比较求积收敛。若求积包含倏逝或向上的射线，直接报错并要求增大
束腰，不静默截断这些分量。有限项角谱在远离束腰处不代表无限精确高斯光束。
本机有限束自由球基准：w0=2 um、355 nm、100 nm 球；FEM 与独立 Mie 逐平面波
叠加的六个内外采样点比较，电场 L2 误差 0.0563%，磁场 0.0598%；5/7 阶参考变化约 6.5e-14。
这不代表粗糙面任意光斑已经达到同样精度。

另一次独立远场复核使用 Mie 散射场在半径 200/400 um 的渐近振幅，与 FEM 体源积分对照：
复振幅相对 L2 误差 0.0311%，球面求积总辐射量误差 0.0410%；两个参考半径的振幅变化为 0.0249%。
后一个数值提示参考仍有有限距离误差，不能把 0.0311% 全归因于 FEM。
原始报告为 `build/release_upgrade/beam_far/audit.json`，球面使用 8 点极向、16 点方位求积。

角谱方法的参考为 [JOSA A 的矢量高斯束分析](https://opg.optica.org/josaa/abstract.cfm?uri=JOSAA-19-2-404)。
这里的离散化、归一化和数值误差由本项目单独验证，并非引用该论文作为软件正确性证明。

## 2. 出瞳像差

归一化局部出瞳坐标 X=u/NA、Y=v/NA、r²=X²+Y²：

```text
W_nm = a*sqrt(6)*(X^2-Y^2)
     + c*sqrt(8)*X*(3*r^2-2)
     + s*sqrt(5)*(6*r^4-6*r^2+1)
P_aberrated = P * exp(i*2*pi*W_nm/(1000*lambda_um))
```

a、c、s 分别为散光、X 方向彗差、球差系数；在完整均匀单位圆上是各项 RMS nm，
若出瞳被晶圆地平线裁切，或照明非均匀，并不等于裁切后强度加权 RMS。
三路使用相同系数，但各自局部光轴坐标不同。纯相位不改总透过功率，会改变光斑和有限相机 ROI 的能量。
偏振仍按矢量衍射传播，不由强度图反推。
基函数约定可与 [TorchOptics 的 Zernike 示例](https://torchoptics.readthedocs.io/en/stable/examples/aberrations/zernike_aberrations.html)
对照；成像积分背景见 [矢量 PSF 理论](https://psf-generator.readthedocs.io/src/theory/basic.html)。

## 3. 相机

相机使用“有颗粒时的总散射通量”，包含粗糙面与相干干涉，不包含被排除的镜面反射光。
每个像素对离散像面做面积重叠积分，不只读取像素中心。随后：

```text
N_photon = P_pixel * exposure / (h*c/lambda)
mean_signal_e = QE * N_photon
mean_total_e = mean_signal_e + (dark_current + background_rate)*exposure
measured_e = min(Poisson(mean_total_e), full_well) + Normal(0, read_noise)
```

输出的是电子数而非 ADC 灰度码；读噪声允许负值。满阱在读出前截断，所以读出值可能略高于满阱。
三路使用从同一主种子派生的不同随机序列；不复用同一张噪声图。各行使用共同绝对色标。
理想 SNR 未计饱和非线性，饱和后不能继续当作有效测量 SNR。
ROI 超出计算视场会报错，不补零、不周期回绕；增加 padding 不扩大视场，应提高 pupil samples 或缩小 ROI。

## 4. 缓存、内存与复现

缓存只保存两组复出瞳振幅。SHA-256 输入包含四个真实体源数组的内容、形状、类型、
波长及半空间介电常数；另加 NA、倾角、采样数和算法版本。改变粒径或照明导致的源变化
会自动失效，不能再出现“远场变了而物镜沿用旧数据”的缓存问题。
改倍率、离焦、像差、透过率或相机参数可以复用；改 NA、倾角或采样数会重新做辐射积分。
缓存读取损坏时退回计算，写缓存失败不使物理结果失效。缓存是可删除的中间数据，不是验证证据。

compact 省略像面 `image_e_*`、`image_hz0_*`，保留复出瞳及各项强度。
同一 128 点、padding=8 三路例的存档从 705,670,087 字节降到约 124,778,816 字节，减少约 82.3%。
精简过程不改变数值精度，不改变采样；全复场可由原始源使用 full 模式重建。
最终默认路径复算存档为 124,779,672 字节；与原始全存档共有的数值数组逐值一致。
同一次本机测量，不含 FEM 求解的冷缓存重成像为 68.01 秒，三路缓存命中后为 11.73 秒，
两者都包括压缩存档与绘图。此为单次端到端测量，不是所有硬件或工况的固定速度保证。
不要仅保留 PNG 后删除唯一原始体源，图片不能用于复数重成像。

远场批量矩阵实现已与原始实现逐值校验，但本机第一轮计时更慢，因此正式默认保持实测更快的
逐方向路径。新批量实现保留在 radiation.py 作为测试候选，未虚报加速。
真实提速来自线程配置和重复成像的出瞳缓存；结果写盘量也明显减少。

## 6. 本轮边界与粗糙度实测

固定 355 nm、100 nm 球、间隙 10 nm、RMS 2 nm、20 倍、三路 NA 0.5、倾角 +45/-45/0 度。
三阶物理区、外半 PML 二阶、32 点光瞳，比较的是三路全像面散射功率，不是相机 ROI。

| 改动 | +45 度功率变化 | -45 度功率变化 | 0 度功率变化 |
|---|---:|---:|---:|
| 物理域半径 0.22 → 0.24 um | -0.2068% | +0.0481% | -0.1436% |
| PML 厚度 0.16 → 0.20 um | -0.2245% | -0.0019% | -0.2502% |

改变域或厚度会重新生成网格，变化包括重新剖分误差。这是两点敏感性检查，不是渐近收敛证明，
也不是所有像素或界面峰值都达到 0.25% 精度。光瞳 32 点仅用于同采样比较，正式图像仍建议至少 128 点。
两个四线程大算例分别在 12.176/12.121 GiB 触发保护，保留失败报告；单线程重试全部完成，
计量峰值分别为 10.641/10.390 GiB。没有提高 12 GiB 限额，没有在失败后导出伪结果。

同样数值配置下，种子 7/8/9 的独立粗糙面三路功率（pW）：

| 种子 | +45 度 | -45 度 | 0 度 |
|---|---:|---:|---:|
| 7 | 174.737 | 213.748 | 58.132 |
| 8 | 183.404 | 193.305 | 40.834 |
| 9 | 170.993 | 153.445 | 35.754 |
| 强度均值 | 176.378 | 186.833 | 44.907 |
| 样本标准差 | 6.366 | 30.668 | 11.732 |

平均的是独立形貌的强度/功率，绝不把不同随机表面的复振幅相干平均。
中路形貌差异显著，三个种子不足以证明统计收敛；还需要更多形貌、实际 PSD 和粗糙区域大小检查。
原始参数、失败与重试资源记录位于 `build/release_upgrade/batch.json`；汇总为 `sensitivity_summary.json`。
