# 颗粒、整光斑粗糙面与真实照明：实现及校验记录

日期：2026-10-10。数值证据保存在 `build/model_campaign_20261010`。

本文区分实现完成、指定算例验证和完整物理模型认证。后者目前没有完成，不将一阶 SPM 与局部 FEM 的混合近似称为全晶圆 Maxwell 解。

## 1. 统一颗粒与粗糙面

混合远场使用复振幅：

```text
A_without = A_whole_SPM + A_local_FEM_without - A_same_local_SPM
A_with    = A_whole_SPM + A_local_FEM_with    - A_same_local_SPM
DSC       = |A|^2
```

局部三角面与整光斑高度场来自同一母表面，使用共同坐标、入射角谱、偏振、绝对功率归一化与复相位。减去的是相同局部三角面的 SPM 振幅，不是强度，避免重复计入局部粗糙散射。颗粒变化场满足：

```text
A_with - A_without = A_local_FEM_with - A_local_FEM_without
```

本次新母表面实际完成了有颗粒/无颗粒的配对 FEM、远场、三路独立成像和 XZ/XY/YZ 局部近场。上述变化场恒等式的相对误差为 `9.80e-17`。这只能证明组合代数与相位去重一致，不证明近似模型没有物理误差。

新算例参数为 266 nm、75°、p 偏振、1 W、晶圆面高斯目标直径 2×2 μm、100 nm 球形颗粒、颗粒 n=1.59/k=0、晶圆 n=5.57/k=0.387、间隙 10 nm、Gaussian PSD 的平稳 RMS=2 nm/L=0.05 μm；三路 NA=0.5，倾角为 +45°/-45°/0°，倍率 20。

这些 n/k 是固定配置输入，不是自动查表得到的 266 nm 材料色散；预测实际 PSL/晶圆时需使用该波长下正确的光学常数。

新母表面宽 48.375 μm，原始 FFT 合成父表面宽 96.75 μm。扩大 FFT 合成域会改变随机实现；因此已经重新求解局部 FEM，没有将新表面与旧 FEM 结果拼接。

限制：外部粗糙面到颗粒再返回外部的高阶多次散射未求解；局部 FEM 可含局部耦合，但不能替代整晶圆的全局耦合验证。近场图只覆盖局部 FEM 域。

## 2. 范围、网格与边缘渐隐

选尺寸算法改为先倍增寻找覆盖区间，再二分到约 1% 的尺寸容差，替代每次扩大 25% 的选择方式。示例最小规划宽度从旧 7.5 μm 变成约 6.047 μm，渐隐加权入射覆盖约 99.01%。这个变化是规划效率优化，不是散射精度改善。

**覆盖 99% 入射功率，不代表散射误差低于 1%。** 粗糙面产生的不同位置散射振幅相干叠加，弱照明尾部仍会改变远场相位和成像。

同一 FFT 父表面的范围审计实际比较了 6.047、12.094、24.188、48.375、72.563、90.703 μm，没有周期复制或重新抽样。最末两档在 96 阶孔径积分下的三路复场相对变化为约 0.719%、0.784%、0.724%。初次检查仍不通过：照明积分只出现一次稳定细化，且第一路 64→96 阶孔径积分的功率变化约 1.089%。进一步复核记录在 `range_refined/range_report.json`，原始未通过报告保留在 `large_range/range_report.json`，不得忽略积分检查仅凭范围变化宣布通过。

最终独立细化使用 3201 阶照明和 96/144/192 阶孔径积分。192 阶下最后两档的三路复场变化为 **0.7161%、0.7795%、0.7257%**；144→192 阶三路功率变化为 **0.1187%、0.02454%、0.1442%**，范围变化指标本身随角度积分细化的变化均小于 0.00283 个百分点。加上 FFT/直接积分检查，此组有限父表面上的外部 SPM 数值目标通过；`full_model_converged` 仍为 false。

另外，在旧父表面相同 28.125 μm 范围、相同频带下做了空间/渐隐审计：

| 改变 | 三路最大复场变化 | 判断 |
| --- | ---: | --- |
| 网格间距增加一倍 | 19.68% | 不可采用 |
| 网格间距减半，Fourier 插值原有频带 | 0.00228% | 此项通过 |
| 渐隐宽度减半 | 0.106% | 此项通过 |
| 渐隐宽度加倍 | 0.152% | 此项通过 |

这里的加密没有增加新的 PSD 高频模式，不能据此证明 PSD 高频截断误差已收敛。该审计也没有改变局部 FEM 网格/PML。

**范围审计不会自动修改生产源。** 本次 `large_hybrid` 的实际生产窗口仍为约 6.047 μm；其图像不应被描述成 90.703 μm 收敛窗口的成像。报告保留生产窗口和审计窗口各自的参数，不覆盖源文件，不隐式替换复相位。

## 3. 独立物理校验

使用同一小三角粗糙面、同一照明、无颗粒条件，将表面高度缩放到平稳 RMS=0.2 nm，独立比较直接 FEM 体源与一阶 SPM。FEM 采用 P1、59,606 自由度；复场 60 个方向样本的相对 L2 差异为 0.879%。没有将拟合振幅因子用于输出。

1 W 入射下的绝对散射功率为：

| 积分范围 | FEM (nW) | SPM (nW) | FEM/SPM |
| --- | ---: | ---: | ---: |
| 上半球 | 95.1706 | 94.7732 | 1.00419 |
| 第一路 | 16.0232 | 15.8338 | 1.01196 |
| 第二路 | 22.8932 | 23.0974 | 0.99116 |
| 第三路 | 22.0950 | 21.9294 | 1.00755 |

因此上半球功率差约 0.419%，但第一路差约 1.196%，不能写成“所有通道 FEM 与 SPM 都在 1% 内”。角度积分 12→18 阶的最大相对变化为 `7.40e-6`。

在半径 0.209 μm、排除 PML 的控制球内，检查总场（入射+反射+散射）的 Poynting 通量和材料吸收：

```text
P_in  = 0.115767015 W
P_out = 0.071698954 W
P_abs = 0.043966145 W
closure = |P_out + P_abs - P_in| / P_in = 0.0880351%
```

球面 24→40 阶积分变化约 0.000952%；裁剪体积分 5→9 阶变化约 0.086904%。这一指定算例通过 1% 的闭合检查。体积分使用元素内球形裁剪近似，保留独立积分误差；闭合并不是严格 FEM 离散误差上界。

控制球只截获部分入射光，`P_in` 不是整束 1 W；散射半球能量也不应强行等于入射功率。该验证不包含镜面项的 DSC，也不认证较高 RMS、颗粒、不同材料、网格/PML 或全晶圆耦合。

此前同面低高度检查中，2 nm/P1、0.5 nm/P1、0.2 nm/P1 的所选方向复场差约为 9.78%、1.92%、0.879%，0.2 nm/P2 约为 0.832%。这支持低高度趋近一阶模型的趋势，但不是任意工况的解析解证明。

## 4. 统计精度

严格复用原有 16 张 whole-beam SPM haze 的光学参数、7.5 μm/256 节点规划及种子，再追加 112 张独立表面，固定最终样本数 128。没有修改旧结果，没有根据反复查看置信区间来提前停止。

每张表面使用相干照明；不同随机表面平均的是强度和功率，不是复振幅。

| 95% 相对区间半宽 | 原 16 张 | 全部 128 张 | 新增 112 张单独统计 |
| --- | ---: | ---: | ---: |
| 第一路，逐指标 | 8.035% | 2.533% | 2.706% |
| 第二路，逐指标 | 5.905% | 2.971% | 3.306% |
| 第三路，逐指标 | 6.591% | 2.481% | 2.708% |
| 第一路，多指标同时区间 | 10.693% | 3.243% | 3.468% |

| 第三路，多指标同时区间 | 8.772% | 3.176% | 3.470% |

同时区间将半球及所有启用通道纳入 Bonferroni 校正，目标为族级 95%；Student t 区间是独立样本条件下的有限样本近似，不是无需假设的严格保证。两套区间都满足本次 5% 目标。

这是 **haze-only、一阶 SPM、固定有限表面规划** 的统计结果，不是颗粒/FEM 混合的 128 次统计验证。表面范围、PSD 带宽和局部 FEM 误差不包含在这些统计区间中。汇总工具从保留样本重新计算同时区间，写入 `campaign_summary.json`；不改写原有仿真源和旧 16 张报告。

## 5. 真实照明定义

UI 的 `Finite beam definition` 和参数 `beam_definition` 支持：

| 选项 | 长宽物理含义 |
| --- | --- |
| `wafer_gaussian` | 晶圆面目标强度 1/e² 直径，长度沿 Y、宽度沿 X |
| `beam_cross_section` | 与光轴垂直的高斯截面 1/e² 直径；几何投影的晶圆 Y 长度=L/cosθ |
| `wafer_rectangle` | 晶圆面均匀、完全相干矩形包络目标；传播角谱截断后不是理想硬边矩形 |
| `measured_wafer` | 晶圆面强度及可选包络相位的 NPZ 像素输入 |

截面选项采用几何投影后的晶圆面包络模型，不等价于在任意高 NA 下完整求解光束垂直截面的非傍轴聚焦。旧 `beam_profile='gaussian'` 在兼容接口中表示有限包络家族；实际形状必须读取 `beam_definition`，不可仅凭旧字段推断。

激光仍从 -KY 侧沿 +KY 投影方向入射。所有有限照明是单频、全相干角谱，保留原点与入射载波相位；晶圆是 Fresnel 匹配的均匀半空间。

### 实测 NPZ 约定

```python
np.savez('beam.npz',
         x_um=x,                 # 均匀递增晶圆 X 像素中心，一维
         y_um=y,                 # 均匀递增晶圆 Y 像素中心，一维
         intensity=I,            # 二维 [Y,X]，非负有限，非全零
         phase_envelope_rad=phi) # 可选：包络相位，不含 +kY 入射载波
```

每个方向 4..256 个像素，坐标和像素宽度单位 μm；强度可以使用相对单位，软件保留形状并按单独输入的激光总功率归一化。像素作分片常数包络，其 Fourier 变换包含像素 sinc 因子。测量范围外设零，不重建未知尾部。

没有 `phase_envelope_rad` 时，UI 提供 `flat` 或 `reject`。`flat` 明确假设平坦包络相位，不是从强度反演出来的相位；`reject` 拒绝没有相位的数据。文件 SHA256 随源保存，文件内容改变后必须重新计算，不能复用旧散射源。恒定已提供相位与缺失相位的假设在元数据中分别记录。

矩形/实测包络使用单位输入包络峰值 E 作为参考，不称为实际中心辐照度，因为中心可能为零。所有模式的总入射功率均由连续角谱的向下 Poynting/Parseval 积分归一化。

### 掠入射角谱检查

266 nm、75°、声明尺寸均为 2×2 μm 时，传播圆盘外的目标**标量包络谱权重**约为：

| 定义 | 排除标量谱权重 |
| --- | ---: |
| 晶圆面高斯 | 21.672% |
| 光束截面高斯 | 0.135% |
| 晶圆矩形 | 30.653% |

这不是激光损失、透射率或散射能量比例；截断会改变实际光斑，保留的传播场仍归一化为用户设定的 1 W。输入定义不同，其物理尺寸与场不应被强行视为相同。

实测演示输入为合成 Gaussian 强度图，不是实验数据。该演示需要 401→601 阶角谱检查才得到大范围稳定显示，最终变化约 `2.40e-13`；单靠 101 阶会产生明显积分伪像。四种模式的批量背景场与原生 FEM 系数函数在空气/晶圆内部的误差为约 `6.5e-16..1.3e-15`。不在 z=0 比较法向电场，因为它在介电界面两侧本就不连续。

整光斑规划与显示采用独立高阶、分离变量表面积分，不构造巨大原生 FEM 表达式。局部 FEM 在组装前额外检查用户所选阶数与更高阶数，所选域内探针变化超过 0.1% 时拒绝求解。局部检查通过不等于全光斑收敛。

实测输入的 Fresnel 表面总场会比单独入射场需要更高阶积分，规划检查允许继续细化至 1001/1601 阶。另外，像素包络的不同传播分量可产生较快的功率干涉条纹，固定 96 点覆盖积分可能发生空间混叠；矩形/实测模式现使用实际表面网格、分块计算覆盖功率，而不是凭粗显示网格推断覆盖率。回归算例专门检查了能令旧 96 点网格失真的周期条纹。

本次矩形照明和合成实测输入均完成了整光斑 SPM、远场和三路独立像面的端到端单表面计算。它们证明新输入可以进入实际流程，不是仅有 UI；不代表真实测量、统计收敛或新照明下含颗粒 FEM 的完整认证。

超过 151 阶时使用 SciPy 的稳定 Hermite/Legendre 求积实现，并仅剪去小于 `1e-20` 的单个 Gaussian 振幅求积权重；这属于数值极小项处理，不是额外物理角谱截断。大表面积分按行分块，只保留辐射所需的加权总 E，不同时保留整幅 E/H 数组；回归测试确认复振幅与覆盖功率不因分块改变。

## 6. UI 与复现

在 FEM 面板加载完整 hybrid 结果后，`Model checks` 可启动范围检查、网格/渐隐检查、低 RMS 功率及闭合检查，以及 P1/P2 局部检查。P2 采用独立的内存保护。加载 whole-beam haze 结果后可选择固定扩展到 128 张；相同种子不会重复计算，旧结果不被覆盖。

`Hybrid mother range factor` 支持 2/4/8；默认 8。扩大母表面会增加内存、改变新的随机实现，因此在新计算中重新求解局部 FEM。此控制只扩大可供一致裁剪的母域，不会自动扩大生产积分窗口。

关键复现入口：

```powershell
build\ngsolve_env\Scripts\python.exe -m fullwave_prototype.guarded_run --report build/check_resources.json --max-memory-gib 10 --reserve-gib 3 --timeout-seconds 1200 local_spm_validation --source build/hybrid_20261009/verified --output build/check_power --orders 1 --height-scales .1 --power-checks
build\ngsolve_env\Scripts\python.exe -m fullwave_prototype.guarded_run --report build/range_resources.json --max-memory-gib 10 --reserve-gib 3 --timeout-seconds 1200 range_refinement --previous build/model_campaign_20261010/large_range --output build/check_range_refined
D:\anaconda\envs\NIST2\python.exe -m tools.model_campaign_summary --root build/model_campaign_20261010
```

大范围任务应通过 `guarded_run` 执行，建议 10 GiB 作业上限、保留 3 GiB 系统可用内存。限制为周期采样保护，并非操作系统硬上限。原始范围任务峰值计量约 9.82 GiB；更高分辨率不能不检查内存就直接放开。

UI 默认作业内存上限为 10 GiB、超时 30 分钟，避免之前 10 分钟默认预算提前结束已实测需要十多分钟的混合任务。中途取消或触发资源保护的复核不当作通过；细化复核保存带输入签名的孔径样本检查点，重新运行时可复用完成窗口。

最终分块细化耗时约 629 秒，峰值计量约 **7.30 GiB**，最低系统可用内存约 4.39 GiB，完成后没有遗留自有进程。之前触发保护的失败记录仍保留，没有降低系统内存保留线来强行通过。

结果及追溯：

- `large_hybrid`：新母表面配对 FEM、局部三平面近场、远场、三路像面。
- `large_range`、`range_refined`：同一父表面范围与独立积分复核；不替换生产源。
- `surface_mesh`：相同频带的空间采样与渐隐审计。
- `power_check`：小粗糙面 FEM/SPM 绝对功率及控制球闭合。
- `ensemble128`：原 16 张固定扩展至 128 张的独立强度统计。
- `beam_inputs`：四种照明定义、传播谱截断、背景场独立校验。
- `haze_wafer_rectangle`、`haze_measured_wafer`：新输入的单表面端到端流程检查，不作为 128 张统计结果。
- `campaign_summary.json/png`：各项独立证据的汇总，不将不同表面实现混成一个算例。

NIST 平面波 PSD 核的一致性依据为官方 [Roughness BRDF](https://pages.nist.gov/SCATMECH/docs/roughbrdf.htm) 与 [PSD 模型](https://pages.nist.gov/SCATMECH/docs/psd.htm)。核对齐不等于有限相干随机表面的每张图或含颗粒多次散射已与 NIST 等价。

## 7. 保留的边界

本轮最终回归为 243 项通过、16 项依赖相关跳过；NIST2 与隔离 NGSolve 环境均通过代码编译检查。真实 NGSolve 求解、功率/闭合及大范围复核已另外执行，不能用 NIST2 中的依赖跳过代替这些物理验证。UI 已检查 hybrid/统计/验证结果路由和 1480×900、1280×800 的显示。

仍不能认证高阶外部/局部反馈、全晶圆近场、完整 PSD 高频尾、所有材料和 RMS 的 FEM/PML 收敛、实际实验光斑未知相位、任意多层膜及实验检测噪声。严格区分工程近似、数值审计与实验一致性；不通过改倍率或归一化让不同模型“看起来相同”。
